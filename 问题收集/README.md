# WordQuest 问题收集

更新日期：2026-09-24

本目录记录内部测试中发现的问题和待验证的风险。当前开发先处理玩法、界面和学习体验；账号与安全改造放在正式上线前完成。记录问题不代表已经决定具体设计方案。

## 记录方式

- **已确认**：当前代码能直接证明问题存在。
- **待复测**：代码存在风险，需要在实际设备或完整游戏流程中复现。
- **待决定**：需要先确定产品体验，再选实现方式。
- 状态默认是「待处理」；修复后补充结果和验证日期。

## 建议先处理的顺序

1. 先修复地图碰撞和人物行走（WQ-17），自测通过后等待用户复测。
2. 根据用户反馈，再确定「再玩一次」、音频、跨设备词书等体验设计（WQ-02、07、08）。
3. 稳定 AI 故事到游戏通关的主流程（WQ-01、03、04、05），校准学习反馈（WQ-06）。
4. 在正式上线前完成 B 类问题，再整理文档、依赖与测试（WQ-09～16）。

每次内部测试可直接在本文件追加新行，并记录复现步骤、设备、预期结果和实际结果。
